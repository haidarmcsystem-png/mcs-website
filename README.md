# Modern Communication System (MCS) Website

A responsive, static-friendly Next.js website for Modern Communication System.

## Included
- MCS logo and company branding
- EV charging infrastructure & EPC services
- Charger sales & supply
- EV canopy and car parking shed
- Factory shed / industrial fabrication
- Solar & electrical infrastructure
- Testing, commissioning & O&M
- 2,500+ EV projects, 3 bus depot hubs ready, 5 four-wheeler charging hubs
- Project capabilities and execution process
- Contact form that opens a WhatsApp enquiry (no paid backend required)
- Static export enabled for free hosting on Cloudflare Pages

## Run locally
```bash
npm install
npm run build
```
The static output is generated in `out/`.
